AI Agent's Calculations & Assumptions:
1. Mesh Generation (Fine)
•	Fine mesh criteria: 20×20 elements (21 nodes in each direction)
•	Element size: 6000mm / 20 = 300mm elements
•	Total elements: 20 × 20 = 400 elements
•	Node coordinates: Generated at 300mm intervals from 0 to 6000mm
2. Material Properties
•	Elastic Modulus (for fck = 45 MPa):
o	Emod = 5000 × √fck = 5000 × √45
o	Emod = 5000 × 6.708 = 33,541 MPa
•	Poisson's Ratio (standard for concrete):
o	ν = 0.18 (typical range 0.15-0.20)
3. Load Calculation
•	Wheel load: 200 kN = 200,000 N
•	Contact area: 400mm × 400mm = 160,000 mm²
•	Contact pressure (q):
o	q = Load / Area = 200,000 N / 160,000 mm²
o	q = 1.25 N/mm² = 1.25 MPa
4. Corner Loading
•	Load positioned at x1=0, y1=0 (bottom-left corner)
•	Load extends to x2=400mm, y2=400mm
•	This represents the Boeing 747 wheel touching both edges at the corner
5. Foundation Modulus
•	Kx = Ky = Kz = 80 MPa/m (as specified for all directions)
